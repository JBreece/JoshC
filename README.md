# JoshC
repo for learning C

"sudoku" folder contains a recursive backtracking Sudoku generator/solver with rule validation, randomized puzzle generation, user input, manual memory management (malloc/free), and 2 'modes' - one for playing, one for solving.
In my sudoku project I worked through pointers, stack vs heap, array decay, scanf pitfalls, recursion base cases, and I separated solver logic from I/O.

"learning_exercises" folder contains well-documented examples of some basic C learnings which can be reviewed later as a refresher.
